## 🧭 What I actually do

I'm a **full stack engineer with a backend bias**. My day splits roughly: `~65% .NET backend`, `~20% Angular / TS frontend`, `~15% LLM & Azure infra`.

### Backend — primary strength
- Design and build **.NET 8 / ASP.NET Core Web APIs** following **Clean Architecture**, **N-Layer**, **Repository + Unit of Work**, **SOLID** and **Dependency Injection**
- **EF Core** + **LINQ** for data access; **SQL Server** stored procedures, views, and SQL Agent jobs for hot-path KPI computation

- Can also work with **ASP.NET MVC** for legacy / brownfield code, and **Python (Flask-RESTX, aiohttp)** for AI-adjacent microservices

### Frontend — solid, not decorative

- Clean component boundaries, typed services, real forms with validation — not "I copy-pasted a template"

- Multimodal ingestion — **text, voice notes, images** — wired into a single chat endpoint
- Conversation state in **Redis**, streamed responses over WebSockets / Server-Sent Events
- Prompt orchestration / tool-calling patterns, not just one-shot calls

### Data & persistence

## 🔧 Selected engineering work

<sub>Focused on **what I built and how** — not marketing metrics. Most production code lives in private employer orgs, so the descriptions below are the implementation detail, not screenshots.</sub>

### Multimodal AI chat pipeline (.NET 8 + Python + Azure OpenAI)
Chat endpoint accepting **text, voice notes, or image uploads** in a single request. Voice routes through **Azure Speech** for transcription; images hit an OCR + vision pass; all three modalities converge at a shared prompt layer. **RAG** retrieval against **Azure AI Search** grounds responses in curriculum content. Conversation state in **Redis** (session TTL + sliding expiration). Responses **streamed** back over WebSockets for token-by-token UX. Prompt orchestration + tool-calling layer built in **Python (Flask-RESTX + aiohttp)** so the AI team can iterate independently of the main .NET services.

### Python → .NET 8 strangler-pattern migration
Moved revenue-adjacent services (subscription, user management, authorization) from a Python monolith to **.NET 8 Web API** using **Clean Architecture** (Domain / Application / Infrastructure / API). Cutover done behind **feature flags**, endpoint by endpoint, with shadow traffic before flip. Zero downtime. Legacy Python kept running for AI orchestration where it's the right tool.

### 23-project .NET 8 solution (shipped end-to-end, sole developer)
Quiz + content management platform. Domain / Application / Infrastructure / Persistence + three audience-specific API hosts (student / admin / teacher) + shared contracts + testing projects. **EF Core** with migrations, **Hangfire** for scheduled re-indexing and rollups, **Redis** for hot question sets, **AWS S3 + signed URLs** for media (student API never touches the bucket directly), **Swagger/OpenAPI** per host for QA + frontend teams, **Docker**ized with CI/CD.

### IdentityServer4 auth infrastructure
OAuth 2.0 / OpenID Connect / JWT across every service in the platform. Token validation middleware, claims transformation, refresh token rotation, RBAC. Optimized the login path (reduced auth round-trips + targeted cache) measurably on the hot user-login API.

### Real-time factory telemetry (.NET Core + SignalR + SQL Server)
Backend for Industry 4.0 dashboards. **Stored procedures, views, and SQL Agent jobs** for KPI computation — kept the hot path in the database rather than the API tier. **SignalR** live streams to the dashboard (group-based broadcasts per plant / line). Idempotent telemetry ingestion with dedup keys so a reader can drop offline and recover without double-counting production.

### Legacy WinForms maintenance (.NET Framework + Telerik + RDLC)
Maintained and extended a desktop app serving two departments (Investment + Financial) for 100+ rental contracts and automated financial reporting. Rewrote the report layer in **RDLC**, enhanced **Telerik UI** grids for large datasets.

### This site (portfolio) — [ahmed-attia-portfolio.pages.dev](https://ahmed-attia-portfolio.pages.dev/)
Static site in **Astro 5 + Tailwind CSS v4 + MDX content collections**. JSON-LD Person schema, sitemap, near-zero JS shipped to the browser. Auto-deployed on every `git push` via **Cloudflare Pages** Git integration. <sub>*(Source is private; happy to share a walkthrough during a hiring conversation.)*</sub>
